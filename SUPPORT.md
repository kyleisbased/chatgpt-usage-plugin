# Support

For installation help, bug reports, or feature requests, open a public GitHub issue:

https://github.com/kyleisbased/chatgpt-usage-plugin/issues

Before opening an issue, include:

- the phone platform and ChatGPT app version;
- the desktop host platform and ChatGPT desktop app version;
- whether the conversation was opened from ChatGPT **Remote**;
- the Usage Checker plugin version;
- whether the host was running, online, and awake;
- the exact error text with credentials and private account details removed.

Usage Checker supports live mobile checks through ChatGPT Remote. Ordinary cloud-only ChatGPT conversations do not currently expose the required host-native usage capability.

Never post passwords, cookies, tokens, API keys, recovery codes, two-factor codes, screenshots containing private account data, or billing information.

This is a community-maintained project. For OpenAI account access, billing, subscription, or service issues, use OpenAI's official support channels.
