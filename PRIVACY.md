# Privacy Policy

Effective: September 3, 2026

Usage Checker is a skills-only plugin. It does not operate a server, create user accounts, use analytics, set cookies, or collect, transmit, sell, or retain personal data on behalf of its publisher.

When invoked, the plugin instructs ChatGPT or Codex to read usage information already available in the signed-in user's OpenAI account. Depending on the host and its available capabilities, that may include opening the official `https://chatgpt.com/codex/settings/usage` page in an authenticated browser. The workflow is limited to the visible usage allowances, credit balance, and reset times needed to answer the request.

The plugin does not ask users to provide passwords, session cookies, access tokens, API keys, recovery codes, or two-factor authentication codes. It does not modify plans, billing, credits, or account settings.

OpenAI's products process prompts and tool activity under OpenAI's own privacy terms and the user's applicable account or workspace settings. This policy describes only the behavior of the Usage Checker plugin maintained in this repository.

Questions or privacy requests can be submitted through the repository's public support channel: https://github.com/kyleisbased/chatgpt-usage-plugin/issues
